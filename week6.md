## Week 6
In the context engineering blog, writing and selecting add to the context, while compressing and 
isolating remove from it. Writing is human authored, where selecting, compressing, and isolating 
are agent directed. One example is a scratchpad, which would be a file like a JSON or markdown file
checked into git that stores intermediate reasoning or state for the agent.

A fuzzer in C or C++ might find a buffer overflow caused by oversized input that corrupts memory, 
which wouldn’t happen in a memory safe language like Rust. In a memory safe system, a fuzzer would probably 
instead find a logic bug. Such as a bad input causing incorrect parsing
